# v1.4.0 发布前验证

验证日期：2026-10-18（Asia/Shanghai）。

- Windows x64 / .NET 10：`./build.ps1`，31 项核心测试通过，单文件发布成功，`dist` 仅包含 `NetPulse.exe`。
- Speedtest.net JSON 与 XML 目录解析、重复/无效节点过滤、HTTPS 主机别名、布尔型 HTTPS 能力标记、正常 TLS 校验；XML 禁用外部实体。
- 回环 HTTP：真实 JPEG 字节计数、流量上限及末尾 2 字节余量；上传必须返回相同字节数的确认，错误确认与登录页被拒绝；标准延迟响应检查。
- 缓存：两种节点源隔离，相同 ID 不互相覆盖；兼容旧版无 Provider / Protocol 字段的设置与测速网缓存。
- 实际 EXE：`--smoke-test artifacts/v1.4/pre-release --speedtest-net` 通过。分别验证两种节点源的缓存恢复、失败保留、一分钟重试、测速期间顺延、选中节点与已有测速结果保留、关闭自动同步、重启恢复及来源切换隔离。
- 实际联网：获取并同步 12 个 Speedtest.net 候选节点，12 个域名解析成功；自动选点后完成下载和上传。一次受限测试显示下载 100.0 Mbps、上传 170.2 Mbps，每方向最多 5 秒 / 32 MiB。该结果仅为当前环境与所选节点的验收记录，不代表用户线路性能。
- 新图标：ICO 包含 16、20、24、32、40、48、64、96、128、256 像素 32 位透明图像；小尺寸加粗笔画。界面加载和更新流程模拟通过。

发布脚本还会重新执行核心测试和构建，并在公开后匿名下载 EXE、清单和校验文件，比对本地产物哈希。发布后另运行 `--verify-github` 验证旧客户端识别新版及真实 EXE 下载。
