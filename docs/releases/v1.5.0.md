# NetPulse v1.5.0

新增原位自动更新：下载校验完成后替换当前 EXE，并自动重新启动新版。继续单 EXE 分发，无需安装器、单独更新器或运行库。

- 默认每 6 小时检查 GitHub，新版在空闲且没有本次测试记录时自动下载、校验、替换与重启；可单独关闭“空闲时自动安装并重启”。监测和测速期间顺延自动安装。
- “下载新版”改为“更新并重启”。点击后自动完成后续流程，无需选择文件位置或手动运行。当前测试记录会先自动备份为 CSV，用户设置和节点缓存继续保留。
- 更新保持原 EXE 路径和文件名，即使文件被重命名或路径包含中文、空格也可使用。临时启动隐藏副本等待旧进程退出，校验新版的 SHA-256、大小、Windows x64 程序身份及内部版本后替换文件。
- 等到新版界面成功启动才清理旧版备份。新版启动失败或超时时尝试恢复并启动旧版；更新目录不可写、目标只读、同一 EXE 有其他运行实例、文件被占用等情况保留旧程序并提示原因。失败后 15 分钟再自动重试，下载过程中可取消。
- 保留 Speedtest.net 节点/IP 定期同步、测速网与 Cloudflare、自定义 HTTP 节点、测速、延迟/抖动/失败率监测、CSV 导出与新应用图标。

**首次切换提示：v1.4 及更早客户端没有原位替换逻辑，需手动运行 v1.5 一次；从 v1.5 升级后续版本即可自动替换与启动。**
