# v1.5.0 验证

验证日期：2026-10-18（Asia/Shanghai）。Windows x64 / .NET 10。

- 核心验证：34 项测试，覆盖原有网络与 GitHub 更新逻辑，以及自动安装空闲策略、测试记录保护、设置迁移、重试间隔、握手 nonce / 时间 / 路径校验、无效 Windows 程序与 SHA-256 拒绝。
- `tools/verify-self-update.ps1` 构建含同一更新代码的 1.4.99 旧版本测试夹具和 1.5.0 新版，在独立副本中运行实际进程流程。此夹具用于测试更新协议，不代表旧的 v1.4.0 已具备该协议。
- 手动一键更新：原进程退出后，同一路径 EXE 字节变为新版并自动启动，核对内部版本和文件哈希。
- 空闲自动更新：有测试记录、测速中的触发均被顺延；清空记录且空闲后自动进入相同替换与启动流程。
- 启动失败：新版启动故意提前退出，更新器恢复原 EXE 字节并重新启动原版本。
- 损坏更新包及只读目标：原程序保持运行到测试主动关闭，原 EXE 哈希不变。
- 五种场景均使用中文、空格、`&`、`$()` 等字符的路径和重命名 EXE，参数通过 `ProcessStartInfo.ArgumentList` 传递；未调用 shell。验证同步与更新偏好保留，需要时自动备份本次 CSV 记录。
- GitHub Windows CI 运行核心测试、单文件构建和以上真实进程验证。正式发布脚本重新构建，并匿名下载全部公开附件核对哈希；发布后验证旧客户端升级识别、实际下载与 raw 更新清单。
