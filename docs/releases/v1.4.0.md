# NetPulse v1.4.0

新增 Speedtest.net 节点和 IP 定期同步，并启用新的“网络脉搏”应用图标。Windows x64 单文件分发，下载 `NetPulse.exe` 即可运行，无需安装运行库。

- 默认使用“Speedtest.net · Ookla 节点”，动态获取公开节点，检测可达性并解析 IPv4 / IPv6。默认运行期间每 15 分钟刷新，可选 5 / 15 / 30 / 60 分钟，也可手动同步或关闭自动同步。
- 保存最近选择的节点源。Speedtest.net 与测速网分别缓存列表和选中节点，切换来源及重启后恢复；兼容旧版同步设置与测速网缓存。
- 同步失败或取消时保留现有缓存，开启自动同步时 1 分钟后重试；测速与下载更新期间顺延刷新，避免影响带宽测试。定时刷新只更新节点/IP 并做小流量探测，不会自动进行下载、上传测速。
- Speedtest.net 节点使用 HTTPS 与正常证书校验，按公开主机别名连接；检查标准延迟响应和下载 JPEG 标识，上传仅统计服务器确认收到的数据。
- 新应用图标覆盖 EXE、窗口、任务栏和界面左上角，包含 16～256 像素共 10 档透明图像，针对小尺寸优化笔画。
- 保留测速网、Cloudflare、自定义 HTTP 节点、下载/上传测速、延迟/抖动/失败率、CSV 导出和 GitHub 新版本检查。

程序自行实现 HTTP 吞吐测量，未集成 Ookla 官方测速引擎，结果可能与 Speedtest.net 网页或官方 App 不同。部分公开节点不支持此 HTTP 测速方式，可以切换节点或来源。测速会产生实际流量。

旧版可点击“检查更新”，保存新版 EXE 后关闭旧版，再运行或替换新文件，用户设置与节点缓存继续保留。
