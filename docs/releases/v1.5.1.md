# NetPulse v1.5.1

Windows x64 单文件便携版。下载 `NetPulse.exe` 后即可运行。

## 优化与修复

- 优化长时间监测的 P95 延迟统计，通过有序插入和直接读取减少界面刷新的计算量与内存分配，继续使用精确的最近秩计算方式。
- 修复持续监测期间重复测速的摘要混入历史样本的问题，每次测速单独统计本次空闲、下载和上传阶段延迟，完整监测记录继续用于查看和导出。
- 修复更新回滚时状态文件无法写入导致旧版启动退出的问题，先在内存中应用重试间隔，配置写入失败时显示提示。
- 修复无效的版本缓存重置自动更新开关的问题，保留用户关闭的自动检查、自动安装选项。
- 改进更新取消、辅助进程失败清理及结果文件的并发写入，保留原始错误信息，等待辅助进程结束后再清理暂存文件。
- 将节点管理和界面测试拆入独立文件，增加回归覆盖，并在 Windows CI 中执行离线界面测试。

## 更新方式

v1.5 客户端可以检查到此版本。开启自动检查与空闲自动安装后，程序会在空闲且没有本次测试记录时下载、校验、原位替换 EXE 并自动启动。也可点击“更新并重启”，现有记录会先备份为 CSV。

v1.4 及更早客户端需要手动下载新版并替换一次。v1.5.1 支持后续版本的原位自动更新与重启。
