# NetPulse v1.3.0

Windows x64 单文件网络测速与波动监测工具，分发文件为 `NetPulse.exe`，已包含运行库。

- 新增 GitHub 最新版本检查：默认程序运行期间每 6 小时检查一次，也可手动检查或关闭自动检查。
- 发现新版时显示版本号、发布说明和下载按钮；下载完成后核对官方发布的文件大小及 SHA-256。
- 检查失败时保留已发现的新版，并在 15 分钟后重试；测速或下载期间顺延检查，避免干扰网络测试。
- 版本信息优先读取本仓库的 GitHub Releases API，连接失败时读取官方仓库的 `release/latest.json`。
- 保留测速网国内节点、Cloudflare 对照、自定义节点、下载/上传测速、延迟/抖动/失败率、CSV 导出及定期同步节点/IP。

使用：下载 `NetPulse.exe` 后直接运行。客户端发现新版后可将新文件保存到其他位置，关闭旧版后运行或替换，原有用户设置与节点缓存继续保留。

测速结果受所选节点、线路及网络负载影响；ICMP/TCP 探测失败率不能直接等同于链路实际丢包率。
